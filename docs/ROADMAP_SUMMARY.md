# Future Roadmap Summary

The ProTrain AI Platform is designed for iterative scaling.

## ✅ Phase 1: MVP Workflow (Completed)

- Course creation & catalog browsing.
- AI Chatbot for basic RAG-based context answering.
- Registration & manual payment proof uploads.
- Tutor access for attendance and hours logging.
- Baseline Admin dashboard.

## ✅ Phase 2A: Security Hardening (Completed)

- Strict Firestore Rules & Role-Based Access Control.
- Auditing & Error logging.
- Production-ready Cloud Run `Dockerfile` and NGINX configurations.

## 🔜 Phase 2B: Student Portal & Automation (Next Target)

- Automated PDF Certificate generation via Cloud Functions.
- Enhanced Student Dashboard (downloadable materials, grades).
- Automated email notifications (SendGrid/Mailgun integration) for payment confirmations.

## 🚀 Phase 3: AI Enhancement & CRM Integration

- Advanced AI Recommendation Engine (matching career goals to courses).
- CRM sync for marketing.
- PowerBI / Looker Data Dashboards via BigQuery.

## 🏢 Phase 4: Enterprise Expansion

- Single Sign-On (SSO) & Microsoft Entra ID.
- Advanced B2B Corporate Approval Workflows (HR portals).
- Migration readiness (Service layer abstractions for SQL migration if required).
- Native Cantonese AI Voice integration.
